# Disnyz

Welcome to Disnyz, a website dedicated to Disney fans, compiling the biggest worldwide box-office hits from Disney films.


**[The website URL](https://hayrunnisacar.github.io/disnyz/)**


## Description
This project was created to allow fans to discover or rediscover Disney classics from the perspective of their commercial success. It offers a visual exploration of box-office data, making it possible to see which films have made cinema history.


## Features
The site offers several interactive ways to explore the data :
* **Interactive charts** : Visualize the highest-grossing Disney films on Mickey Mouse heads.
* **Timeline** : An interactive timeline ("Once upon a time…") where each flower reveals a movie on hover.
* **Revenue counter** : A counter displaying the total gross box-office revenue.
* **Studio history** : An overview of Disney's history, from its black-and-white beginnings to its greatest successes.


## Technologies Used
This is a front-end project built with:
* **HTML5**: Website structure.
* **CSS3**: Style and layout.
* **JavaScript**: Site interactivity (charts, timeline, counter, animations).
* **JSON**: Data fetching.


## Installation
Disnyz uses `.json` files to load its data. Due to browser security policies, you cannot simply open the `index.html` file directly from your file explorer. The site must be run via a local server so that the `.json` files can be loaded correctly.

**Method:**
1. Clone this repository to your local machine:
   ```sh
   git clone https://github.com/hayrunnisacar/disnyz.git
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension (if you haven't already).
4. Once the extension is installed, go back to the Explorer tab. Right-click on the index.html file.
5. Click on "Open with Live Server" (in the right-click context menu).
6. Your browser will automatically open the Disnyz site on your local server.
